# Contributing to BotFlow

Thank you for your interest in contributing to BotFlow! We welcome contributions of all kinds.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/botflow.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Commit your changes: `git commit -m 'Add your feature'`
6. Push to the branch: `git push origin feature/your-feature`
7. Submit a pull request

## Guidelines

- Keep code clean and well-commented
- Follow the existing code structure and naming conventions
- Test your changes before submitting
- Write clear commit messages
- Update documentation if needed

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub with:
- Clear description of the problem
- Steps to reproduce (for bugs)
- Expected vs actual behavior

## Questions?

Feel free to open an issue or start a discussion for questions.
